# Agent asset authoring routes

Read this routing index **only after** [SKILL.md](SKILL.md) accepts the request and the required [documentation Skill](../documentation-authoring/SKILL.md) has been loaded. Apply the companion to documentation subtasks only; the asset Skill owns contracts and packaging. Select only the relevant destination.

| Request | Load next |
| --- | --- |
| Create or revise an agent Skill, rule, role, reference, template, or module | [Author](author.md) |
| Audit, evaluate, deprecate, or retire an existing agent asset | [Review](review.md) |

For a mixed request, load the second route only when its separate steps become necessary. If neither route matches, stop; do not browse the routed files or infer permission.
