# Skills

Skills are optional, task-specific agent workflows. Each Skill uses `<name>/SKILL.md` as its entrypoint, with supporting files kept under the same directory.

## Available Skills

- [Repository readiness](repository-readiness/SKILL.md) — inspect development prerequisites and report gaps without modifying the repository.

A Skill should define when it applies, inputs, procedure, verification and output. Add its link here when publishing it.
