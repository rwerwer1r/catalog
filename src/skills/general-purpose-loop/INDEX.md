# General-purpose loop routes

Read only after the [Skill gate](SKILL.md) accepts the task. Choose one route by current run state; do not preload every procedure.

| State or need | Load next |
| --- | --- |
| Start or resume a run; establish scope and authority | [Prepare](prepare.md) |
| Readiness accepted; execute or review substantive work | [Cycle](cycle.md) |
| Review finds a narrow, independently useful subproblem or missing perspective | [Focused resolution](focus.md) |
| Review nominates an exit, a blocker, or the cycle ceiling | [Close](close.md) |

Complete readiness before the first cycle. After any entered cycle, closure gates terminal claims. A blocked readiness result is reported directly without opening work routes.
