# Documentation authoring

## Relevance gate

**Use only for** writing, organizing, or reviewing documents, including README.md, SKILL.md, indexes, and documentation subtasks in agent asset authoring. Not for implementing code, packaging unrelated assets, changing permissions, or deployment. If neither applies, **stop here**; do not load routes.

## Essential contract

Higher-priority instructions, authorization, and the target repository's scoped policies override generic defaults for language, layout, metadata, and validation. This Skill **owns reader-facing entrypoint, index, and discovery-metadata guidance**; a calling asset workflow retains packaging, implementation, and tool authority.

Read the applicable instructions and canonical page, then only evidence needed for the next decision. Reuse confirmed context for the same revision. Never invent sources, checks, or requirements.

## Route

After acceptance read [INDEX.md](INDEX.md) and load one route for entrypoints, indexes, general writing, or maintenance; expand on concrete need only. Follow the **target's** README and index naming conventions, not this repository's layout.

**Output:** changed documents and navigation, verified claims and checks, and unresolved limits. Passing structural checks does not prove factual accuracy.
