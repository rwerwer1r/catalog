# Maintain or audit documentation

Use after the [documentation Skill gate](SKILL.md) and [route index](INDEX.md) select maintenance, navigation, or review.

1. Read applicable local repository rules, the nearest introduction and routing index, the affected page, and any directly relevant sources. Avoid unrelated directories.
2. Test the entrypoint gate: does a reader immediately understand purpose, relevance, exclusions, and where to go next? A misrouted reader should be able to stop without opening large documents.
3. Review routing indexes as maps, not tutorials. Ensure each link names a distinct reader intent, targets an existing page, and requires no unrelated pages to be preloaded. Follow local `INDEX.md` or `index.md` conventions; do not create both as competing authorities.
4. Check accuracy, task completeness, headings, metadata, relative links, examples, accessibility, and safe handling of secrets or permissions.
5. For moves and deprecations, preserve stable links where possible, update affected inbound navigation, and state replacements or compatibility impact.
6. Run focused, authorized validators and inspect what they cannot prove. Record passed, failed, not run, or not applicable results with evidence.

Fix the smallest evidenced defect. Do not expand reviews or repeat unchanged checks without a concrete cause.
