# Templates

Templates are starting documents requiring human review and replacement of placeholders. Each template uses `<name>.md`.

## Available templates

- [Decision record](decision-record.md) — record an engineering decision and trade-offs.
- [Handoff note](handoff-note.md) — transfer incomplete work with evidence.
- [Task brief](task-brief.md) — define an outcome, scope and acceptance criteria.

Add new templates to this index.
