# Catalog maintenance

This repository stores reusable instructions and templates, not operational secrets or account configuration.

- Read the relevant asset and its catalog entry before editing.
- Keep instructions scoped to a task. Avoid dependencies on a specific agent, product, or machine.
- Separate guidance from mandatory requirements. Do not claim checks or commands were run when they were not.
- Use examples without private identifiers, personal data, credentials, or real project records.
- When changing an asset, update its entry in `catalog.json` and any links in `README.md`.
- Check JSON syntax, local Markdown links, and the final diff before committing.
