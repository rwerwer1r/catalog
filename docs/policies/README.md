# Repository policies

These policies define **what belongs in `rwerwer1r/catalog` and how its maintained content is governed**. They are not global instructions for other repositories or a collection of general agent-safety advice.

| Policy | Scope |
| --- | --- |
| [Repository](repository.md) | Purpose, ownership, source directories and scope of changes |
| [Assets](assets.md) | Rules for adding, modifying and publishing reusable assets |
| [Documentation](documentation.md) | Canonical document ownership and authoring requirements |
| [Language](language.md) | English as the language of maintained repository content |

Apply the relevant policy when changing this repository. Implementation steps belong in [development](../development/README.md), agent execution and trust boundaries in [AI agent operations](../agents/README.md), and writing techniques in the [documentation handbook](../documentation/README.md).

Catalog assets are **opt-in sources for other projects**. These policies do not automatically apply to a consuming repository.
