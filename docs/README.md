# Documentation

Documentation governs **maintenance of this reusable asset repository**. Distributable source belongs under [src/](../src/README.md).

| Area | Responsibility |

| [Development](development/README.md) | Architecture, contribution workflow, asset lifecycle and validation |
| [Policies](policies/README.md) | Repository scope, reusable asset publishing, documentation and language |
| [AI agents](agents/README.md) | Context loading, maintenance workflow, scenarios and evidence |

## Boundaries

These instructions govern changes to `rwerwer1r/catalog`. They are not automatically published as reusable assets or imposed on other repositories. `src/` is canonical for assets, `catalog.json` lists published entrypoints, and repository policies govern their maintenance.
